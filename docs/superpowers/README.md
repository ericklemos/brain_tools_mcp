# Histórico de design

Os documentos em `designs/`, `plans/` e `specs/` registram o processo de construção do
projeto e são mantidos como histórico. Eles descrevem o estado da época, não
necessariamente o código atual.

Em 2026-10-29 o motor de decisão GGUF (`brain-engine` / `llama-cpp-2`) foi removido.
Onde estes documentos falam em validação semântica, threshold ou GPU, o estado atual é
o ranking lexical descrito no [README](../../README.md) e em
[arquitetura_e_especifica_o_do_brain_tools.md](../../arquitetura_e_especifica_o_do_brain_tools.md).
